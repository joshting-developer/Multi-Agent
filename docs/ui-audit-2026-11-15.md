# 介面掃描 2026-11-15

用共用庫的兩個 Skill 掃描聊天與設定畫面, 依結果開卡修改。掃描對象是 0.1.13 的實際畫面（深色、淺色各看一次, 側邊欄寬 420px, 設定頁寬 1000px）

## 選用的 Skill

| Skill | 用途 | 選它的原因 |
| --- | --- | --- |
| [ui-ux-pro-max](../.agents/skills/ui-ux-pro-max/SKILL.md) | 無障礙、互動、表單與回饋的規則庫 | 可依問題查規則, 涵蓋桌面工具, 不綁行銷頁 |
| [unslop](../.agents/skills/unslop/SKILL.md) | 間距、顏色、文字、圓角等細節的逐層檢查 | 針對既有畫面修細節, 不要求換風格 |

沒選的兩個：design-taste-frontend 以行銷網站的美術方向為主；hallmark 的說明寫明只用在新頁面, 不用在既有設計

兩個 Skill 都以連結方式裝在 `.agents/skills`, 正文仍在共用庫

## 方向

unslop 要求先寫方向再動手。本專案屬於「輕度」, 只修掃描找到的問題, 不換配色、字體與版面

- **產品：** 在 VS Code 側邊欄用 Codex 和 Claude Code 處理同一個工作區的工具
- **性格：** 安靜、精確、像編輯器原生的一部分
- **世界：** 編輯器本身, 顏色全部取自 VS Code 主題變數, 不自訂色票
- **重點內容：** 對話裡的程式碼、工具步驟, 以及帳號的用量條
- **識別細節：** 工具步驟前的狀態圓點

## 沒有問題的部分

- 沒有漸層、光暈、表情符號圖示、驚嘆號、宣傳用語
- 顏色全部來自主題變數, 強調色只用在送出鈕、連結和焦點框
- 危險操作（刪除對話、移除帳號、使用重置券、完整存取）都有原生確認視窗
- 圖示按鈕都有可存取名稱, 鍵盤焦點框保留

## 沒做的建議

- unslop 建議每個畫面有一個視覺重點。側邊欄工具不適合加裝飾, 重點維持在對話內容
- ui-ux-pro-max 的 44px 觸控目標是手機規則, VS Code 是滑鼠操作, 採用 WCAG 的 24px
